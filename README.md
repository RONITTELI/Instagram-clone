# Instagram Clone

A responsive Instagram clone built with HTML, CSS, and JavaScript.

## 🚀 Live Demo

[View Live Demo](https://ronitteli.github.io/Instagram-clone/)

## 📱 Features

- **Home Feed** - View posts from users with like, comment, and share functionality
- **Stories** - Interactive story viewing experience
- **Reels** - Vertical scrollable video reels section
- **Messages** - Direct messaging interface
- **Profile** - User profile page with posts grid

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (jQuery)
- Bootstrap Icons

## 📁 Project Structure

```
instagram-clone/
├── index.html          # Main home page
├── style.css           # Main stylesheet
├── profile.html        # User profile page
├── reel.html           # Reels page
├── story.html          # Story viewer
├── messge.html         # Messages list
├── messagebox.html     # Chat interface
└── img/                # Images folder
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/RONITTELI/Instagram-clone.git
   ```

2. Open `index.html` in your browser

## 🌐 Deployment

This project can be deployed on:
- GitHub Pages
- Netlify
- Vercel

### Deploy to GitHub Pages

1. Go to your repository Settings
2. Navigate to Pages section
3. Select the main branch as source
4. Your site will be published at `https://ronitteli.github.io/Instagram-clone/`
